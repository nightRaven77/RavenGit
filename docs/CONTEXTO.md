# Contexto operativo breve

Revisión: **03/11/2026**, base **`24f9498` · previos para v1**. Versión **1.0.0-beta.1**, alcance funcional congelado; candidato Windows del 30/10 construido e instalado localmente con recorrido básico. La matriz WinQA del 02/11 se detuvo por perfil beta previo y falta de usuario limpio; el perfil se conservó. En macOS el DMG verificado se instaló en `/Applications` y abrió desde Finder; la prueba local incluyó historial, cambios y Stash guardar/restaurar en fixture desechable. Finder y Dock confirmados. `codesign --verify --deep --strict` valida la firma ad hoc; `spctl` falla con error interno tanto en bundle como en la copia instalada y `syspolicy_check distribution` no concluyó. No se modificó seguridad del sistema. Notarización, firma reconocida, primera ejecución de Actions y publicación siguen pendientes. Decisión del usuario: al cerrar beta, avanzar directamente a v1 sin otro RC; las puertas pendientes aún impiden declararla validada.

## Implementado

- Tauri 2, React/TypeScript, Rust y Git CLI del sistema; Windows y macOS. Biblioteca/colecciones, inicialización/clonado, historial/diff, commit/amend, ramas y transporte disponibles.
- Merge, rebase lineal, cherry-pick/revert, Stash recuperable y tags ligeros/publicación selectiva; conservan límites y aceptación parcial.
- D.2a–c: consultar Base/Local/Entrante, guardar resolución textual con respaldo y preparar ese archivo mediante revisión independiente. No hay continuación/commit automático; etapas ausentes/binarios/enlaces siguen externos. [Guardado](validacion/Editar_conflictos.md), [preparación](validacion/Preparar_resoluciones.md).
- D.2d: recuperar respaldos durante merge compatible, con comparación y copia del contenido actual antes de reemplazar; no cambia índice/HEAD ni continúa. Los respaldos no certifican un HEAD histórico. [Alcance](validacion/Recuperar_respaldos_conflictos.md).
- D.3: rebase interactivo acotado a 1–50 commits lineales; ordenar/pick/reword/squash/fixup/drop, respaldo y recuperación. Sin exec/edit/autosquash/merges. [Alcance](validacion/Rebase_interactivo.md).
- C.2: Preparar todos/seleccionados con casillas, contador y una transacción de índice; conserva preparación individual/por bloque. No hace commit ni incluye submódulos. [Alcance](validacion/Preparacion_multiple.md).
- Actividad persistente acotada a fecha/operación/estado/nombre de carpeta, exportación con nombres neutros y borrado consentido implementados. Los avisos generales cubren las operaciones Git principales, confianza y perfiles SSH; no guardan salida Git ni reintentan. [Alcance y límites](validacion/Actividad_diagnostico_avisos.md).
- Perfiles SSH por host/alias y diagnóstico local del agente implementados; credenciales delegadas a OpenSSH/Git/sistema. [Alcance y límites](validacion/Cuentas_SSH.md). Aceptación real por cuenta/proveedor y releases con `gh` siguen pendientes.
