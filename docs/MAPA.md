## Comandos focalizados

Desde la raíz, con Node/npm, Git y Rust instalados:

```sh
git status --short
git log -3 --oneline
rg -n 'símbolo' src/ChangesPanel.tsx src-tauri/src/changes.rs
npm test -- src/ChangesPanel.test.tsx
cargo test --manifest-path src-tauri/Cargo.toml changes::tests
git diff --check
```

Sustituye módulo/archivo por el área afectada. Si Cargo no está en PATH, utiliza su instalación local; no codifiques rutas personales en scripts compartidos. Usa `--offline` sólo si las dependencias ya están disponibles.

Validación amplia cuando corresponda: `npm test`, `npm run build`, `cargo test --manifest-path src-tauri/Cargo.toml`, `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check`, `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`. Formato de archivos modificados: `npx --no-install prettier --check <archivos>`.

Build nativo: `npm run tauri build -- --debug --no-bundle`. Si RavenGit bloquea el ejecutable, pedir cerrar app/dev; no terminar procesos del usuario automáticamente. Un build no acredita un recorrido nativo ni una publicación.

`dev/` contiene fixtures de interfaz; `docs/validacion/` conserva evidencia histórica. Artefactos generados y dependencias no son contexto inicial. No eliminar ni mover evidencia para ahorrar lectura.
