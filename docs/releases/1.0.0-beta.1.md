# RavenGit 1.0.0-beta.1 · notas del candidato

Beta de Windows x64 para pruebas privadas. No es v1 estable. El candidato local actual y su hash constan en el `registro del 02/11` (archivo no incluido en este repositorio: `Compilacion_previa_v1_Windows_2026-11-02.md`); los `candidatos del 30/10` (archivo no incluido en este repositorio: `Beta_1_Windows_2026-10-30.md`) y `29/10` (archivo no incluido en este repositorio: `Beta_1_Windows_2026-10-29.md`) son históricos y tienen otros hashes aunque compartan versión.

## Incluido

- Biblioteca y colecciones locales, inicialización/clonado e historial con grafo y diff.
- Preparación individual/múltiple, commit/amend, ramas, Fetch/Pull/Push y etiquetas con revisión explícita.
- Merge, rebase lineal/interactivo acotado, cherry-pick/revert y Stash conservando entradas y respaldos.
- Perfiles SSH y diagnóstico local; Git/OpenSSH/sistema administran las credenciales. No hay OAuth ni almacén propio de claves o tokens.
- Registros de recuperación de rebase y Stash publicados después de escribir/sincronizar un temporal completo, sin sobrescribir registros anteriores. Errores, bloqueos o estados incompletos no provocan reintentos automáticos.
- Actividad acotada, avisos y diagnóstico sanitizado.

## Probar la beta

La aplicación se identifica como **RavenGit Beta** y usa una biblioteca/configuración separada de la instalación habitual. Abrir un repositorio en la beta sigue operando sobre sus archivos reales: para probar mutaciones utiliza repositorios desechables o con respaldo independiente.

Requiere Git instalado y disponible, y Microsoft Edge WebView2. El instalador estándar puede necesitar conexión para obtener WebView2 si no existe. La beta no instala Git ni modifica automáticamente SSH, credenciales, certificados o claves conocidas.

Guía de prueba: abrir un repositorio local de prueba, revisar historial/diff, preparar y confirmar un cambio, guardar/restaurar un stash y comprobar los mensajes de revisión. Las conexiones y publicaciones se solicitan por separado; no hay Push automático.

Para ejecutar la aceptación en otra máquina Windows, seguir la [matriz funcional instalada](MATRIZ_BETA_1_WINDOWS.md): incluye verificación del paquete, fixtures desechables, instalación limpia, casos locales, recuperación, accesibilidad, transporte y actualización/desinstalación, con una plantilla para registrar cada resultado. Git/WebView2 son requisitos de ejecución; Node, Rust y Visual Studio sólo se necesitan si se compila desde fuente. Los resultados de origen no aprueban la nueva máquina.

## Límites conocidos

- macOS y sus paquetes no se certifican con este candidato de Windows.
- La validación por proveedor/cuenta y HTTPS no está completa; un diagnóstico local no confirma identidad ni permisos del repositorio.
- La recuperación puede exigir revisión desde Git cuando hay locks o estado incompleto. No se borran bloqueos automáticamente ni se garantiza recuperación frente a corte eléctrico.
- Pendientes adicionales de rendimiento a gran escala, accesibilidad, instalación/migración y firma antes de v1 estable. El estado de firma concreto se registra junto al artefacto.
- Stash conserva la entrada; no incluye pop, borrado ni aborto automático. Rebase interactivo no admite exec/edit/autosquash/merges. Casos avanzados de conflictos/binarios continúan en Git externo.
- Releases con GitHub CLI, PR/MR, worktrees, submódulos y LFS no se incorporan en esta beta.

Para reportar un fallo incluye versión, Windows/arquitectura, pasos con una fixture, comportamiento esperado y observado. No adjuntes credenciales ni registros privados sin revisar.
