# RavenGit 2.0.0

Nueva generación de **RavenGit** para Windows x64, macOS Apple Silicon y Linux x64, con identidad visual renovada, grafo estilo **Tributary** y motor híbrido local **Rust + `gix` (*gitoxide*)**, manteniendo **100 % de compatibilidad** con la biblioteca y configuración local de versiones `1.0.x`.

## Novedades destacadas

- **Grafo Tributary e interfaz renovada:** avatares circulares de autor, columna `Rama / Tag` redimensionable (`120–280 px`), iconos duales local/remoto colapsando remotos coincidentes, separadores temporales (`Hoy`, `Esta semana`, `Anterior`), filtro rápido en barra lateral e iconos SVG animados en CSS.
- **Modo Simple en 1 clic:** alternador en barra superior y barra de estado para priorizar el flujo cotidiano.
- **Motor híbrido `gix` + Multi-repositorio:** lectura local ultrarrápida, hasta 12 pestañas con sesiones y bloqueos aislados, fila **WIP** conectada a `HEAD` en tiempo real y gestor de **Git Worktrees**.
- **Cambios, diffs visuales y ajuste de líneas:** visor unificado y dividido con ajuste de líneas (`Ajustar líneas`), resaltado de sintaxis, diferencias intra-línea, minimapa, staging por línea y comparador visual de imágenes.
- **Inspección avanzada y forjas opt-in:** búsqueda profunda (`-S` / `-G`), historial `--follow`, **Git Blame**, comparación de rango (`Shift+Clic`), rebase interactivo visual, editor de conflictos a 3 vías, **Git LFS / Submódulos** y consulta opt-in de **Pull Requests / MRs** (GitHub `gh` / GitLab `glab`).
- **Seguridad 2.0 y documentación:** snapshots locales automáticos/manuales, **Undo / Redo** con vista previa, respaldos `.git/ravengit-restore/`, **Guía rápida** de 6 pasos integrada, guía filtrable de atajos (`?`), 7 temas y [manual modular con capturas](../manual/README.md).

## Actualización desde versiones 1.0.x

RavenGit `2.0.0` conserva intactos `identifier` (`dev.ravengit.desktop`), `productName` (`RavenGit`) y los formatos locales `settings-v1.json` y `library-v1.json`, por lo que tus repositorios, pestañas, preferencias y temas se mantienen sin migrar nada:

- **Windows (NSIS `currentUser`):** al ejecutar el instalador `.exe`, NSIS reemplaza automáticamente la instalación `1.0.x` del mismo usuario (registrada bajo el mismo `identifier` y directorio por usuario) sin requerir desinstalación manual previa. *(Si alguna vez instalaste una build firmada y otra sin firmar, o cambiaste de modo de usuario a máquina, Windows podría pedir desinstalar la previa desde «Aplicaciones instaladas».)*
- **macOS (`.dmg`):** al arrastrar `RavenGit.app` a `/Applications`, macOS pregunta si deseas **Reemplazar** la versión `1.0.x` existente; elegir **Reemplazar** actualiza el paquete conservando la configuración en `Application Support`.
- **Linux (`.deb` / `.AppImage`):** `sudo apt install ./ravengit_2.0.0_amd64.deb` (o `dpkg -i`) actualiza directamente sobre un `.deb` `1.0.x` anterior; si usas `.AppImage`, basta sustituir el binario ejecutable.

## Distribución

- **Windows x64:** el workflow solicita firma Authenticode para el ejecutable y el instalador NSIS mediante SignPath (integración vía API directa / PowerShell).
- **macOS Apple Silicon (`arm64`):** el workflow genera un DMG arm64 con firma ad hoc. La notarización de Apple sigue pendiente de credenciales y configuración de Developer ID.
- **Linux x64:** el workflow genera paquetes `.deb` y `.AppImage` en `ubuntu-22.04` mediante `npm run release:build:linux`.

Los artefactos incluyen licencia, sumas SHA-256 y un manifiesto de entrega. Esta nota no sustituye la validación por plataforma ni publica un release automáticamente.
