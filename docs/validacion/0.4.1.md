# RavenGit 0.4.1 — barra de comandos

Fecha: 20 de octubre de 2026. Ajuste de interfaz a partir de la referencia aportada por el usuario; no añade nuevas operaciones Git.

La barra compacta muestra repositorio y rama, iconos con etiquetas y separadores de grupos, conservando Obsidian/Azure. Rama es contexto informativo; no simula un selector de checkout.

| Acción | Comportamiento |
| --- | --- |
| Abrir | Selector existente de repositorios locales |
| Cambios | Vista de staging y commits |
| Actualizar | Relectura local del historial y referencias |
| Fetch | Abre Remotos; se elige destino y se confirma allí |
| Push | Abre Publicar; mantiene revisión y confirmación existentes |
| Buscar | Abre Historial y enfoca el filtro sobre lo cargado |
| Clonar, Deshacer, Rehacer, Pull, Rama, Stash, Pop, Terminal | Inactivos; explicación de implementación pendiente |

La barra no contacta servidores al mostrarse ni al navegar. Las conexiones se realizan desde las acciones explícitas de las vistas correspondientes. Sin repositorio sólo se permite Abrir. Durante operaciones en curso la barra se bloquea. Los comandos pendientes usan aria-disabled y siguen siendo descubribles por foco para explicar su estado; no ejecutan callbacks. En la ventana estrecha se mantiene una tira desplazable horizontalmente.

Validación: 29 pruebas de interfaz aprobadas, incluidas cuatro nuevas para rutas de acciones, comandos pendientes, estado sin repositorio y bloqueo durante operaciones. Build TypeScript/Vite aprobado. La revisión visual se hizo con `dev/commands.html`, datos sintéticos y callbacks sin acceso a Git; se revisaron 1280 px, 900 px y el acceso al último comando de la tira. Compilación nativa macOS arm64 de desarrollo aprobada con `npm run tauri build -- --debug --bundles app` (RavenGit.app).

No se repitieron las 44 pruebas Rust de 0.4.0 porque esta modificación no cambia su lógica. La compilación nativa comprueba la integración del bundle, no una interacción nativa de extremo a extremo. Accesibilidad integral, pruebas de proveedores y Windows/Linux siguen pendientes.
