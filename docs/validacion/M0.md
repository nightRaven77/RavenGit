# RavenGit · Primer prototipo M0

> Registro histórico del prototipo 0.1.0. Sus cifras, funciones y rutas pertenecen a ese incremento. Para abrir el proyecto actual usa el [README](../../README.md); para avance y pendientes consulta el [roadmap](../../ROADMAP.md) y el [índice de evidencia](README.md). Los pendientes aquí enumerados pueden tener evidencia posterior, sin cerrar por ello toda la aceptación de M0.

**Estado:** implementado como prototipo de lectura; M0 sigue abierto. **Versión:** 0.1.0 del código. **Base de producto:** documentación v0.2, stack y dirección visual aprobados. **Fecha:** 19 de octubre de 2026.

## Qué está implementado

- Proyecto Tauri 2 con React/TypeScript y núcleo Rust.
- Selector de carpetas para repositorios Git locales con árbol de trabajo.
- Historial real de Git, paginado en lotes de 200 commits, con renderizado de filas virtualizado.
- Grafo con todos los padres, referencias locales/remotas, etiquetas y HEAD separado.
- Inspector de autor, fecha, hash y padres. Diff unificado contra el padre seleccionado, incluyendo elección de padre en merges y diff raíz contra árbol vacío.
- Búsqueda por mensaje, autor y hash dentro de lo cargado, con alcance visible.
- Actualización manual y rechazo de paginación si las referencias o HEAD cambiaron.
- Identidad Obsidian / Azure / carmesí y disposición de escritorio inspirada en GitKraken.

Las referencias remotas son las guardadas localmente; no se hizo fetch. Seleccionar una rama en el lateral sólo localiza su commit y no cambia de rama.

## Seguridad y límites implementados

Sólo hay comandos de lectura expuestos. Git se inicia con argumentos separados y sin shell; los diffs deshabilitan herramientas externas y textconv. No se exponen operaciones de escritura, red, cuentas o credenciales. Se limita la salida de cada proceso a 2 MiB y el tiempo a 15 segundos; una salida excesiva se rechaza con mensaje, sin presentarla como completa.

El parser rechaza salidas que no puede representar como UTF-8. Se informa el estado shallow. Los datos de commits se renderizan como texto. Esto describe controles implementados; no equivale a una auditoría de seguridad completa.

## Qué falta antes de cerrar M0

1. Validar visualmente el flujo nativo con el fixture, incluyendo selección de ambos padres del merge, búsqueda y actualización externa.
2. Medir grafo y diff con el fixture de 100 000 commits: p95 de 20 repeticiones, memoria, caché fría/caliente y hardware registrado. No hay cifras de rendimiento de la aplicación todavía.
3. Comprobar accesibilidad con teclado y lector de pantalla en Windows/macOS; verificar contraste y escalado.
4. Compilar y probar en Windows. Linux conserva su fase posterior.
5. Resolver límites encontrados y definir versiones mínimas, distribución de Git y estrategia de firma/actualización.

Después de esa base: staging y commit, y luego operaciones avanzadas con recuperación. No se añadieron funcionalidades de escritura en este incremento.

## Limitaciones de esta versión

Sin diff dividido, detección de renombres, resaltado de sintaxis, paneles redimensionables, workspaces persistentes, APIs de proveedores ni funciones de publicación. La búsqueda sólo alcanza commits cargados. No hay detección automática continua de cambios: se usa Actualizar. El diff no está virtualizado y requiere medición visual. El desplazamiento profundo del historial usa offset y aún no está optimizado. Repositorios bare no admitidos.

La licencia pública sigue pendiente. Los iconos del bundle proceden de la plantilla y son temporales; la identidad textual y cromática es RavenGit.

## Reproducir las verificaciones

En la carpeta del proyecto:

```sh
npm ci
npm run build
npm test
cargo test --manifest-path src-tauri/Cargo.toml --offline
cargo clippy --manifest-path src-tauri/Cargo.toml --offline --all-targets -- -D warnings
npm run tauri build -- --debug --bundles app
```

En una máquina nueva, quitar `--offline` para descargar dependencias Rust. El último comando es de empaquetado macOS; no sustituye la prueba de instalación limpia ni la ejecución en Windows.

Fuentes de configuración consultadas: [crear proyecto Tauri](https://v2.tauri.app/start/create-project/), [comandos Rust](https://v2.tauri.app/develop/calling-rust/) y [selector de carpetas](https://v2.tauri.app/plugin/dialog/). Las comprobaciones de RavenGit indicadas arriba se basan en ejecución local, no en las afirmaciones de estas fuentes.
